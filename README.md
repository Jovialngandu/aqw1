## AQW1
L'information Tech, sans le bruit.

AQW1 est un agrégateur d'actualités minimaliste conçu pour une lecture pure. Pas de distractions, pas d'authentification complexe, juste l'essentiel.

## ✨ Fonctionnalités
Minimalisme : Interface épurée, focus contenu.


Gestion intelligente : Distinction claire entre pannes réseau et erreurs serveur.

Native : Fluidité optimale avec React Native.

## 🛠 Tech Stack
Framework : React Native (Expo)

State Management : Redux Toolkit

## 📦 Installation
```bash
git clone https://github.com/Jovialngandu/aqw1.git
cd aqw1et
npm install
npx expo start
```
## 💡 Philosophie
Contraction de "A QUIET". Lire l'actualité ne devrait pas être une source de distraction. Un projet axé sur la simplicité.
Développé avec passion pour la simplicité.
